# TKT-20260302-114 — print service degradation, Fabrication office

An IT trouble ticket as an artipod: [ticket.mdy](ticket.mdy) carries the
status machine in front matter, [updates.md](updates.md) is the running log,
and each lifecycle step is a tag (`opened` → `triage` → `fix` → `closed`).
Diagnostics arrive as a layer at `triage` — including a screenshot and a
support bundle — so you can watch the evidence show up in the manifest at the
moment the story says it did.
